# BLARE Alarm Clock

## About
A custom alarm clock project built around the Seeed Studio XIAO ESP32-C3.

## Project Structure
- `PCB/` — KiCad project files, schematic and PCB layout.
- `Production/` — Gerber and drill files for PCB manufacturing.
- `CAD/` — 3D model of the clock case and assembly.
- `Firmware/` — Alarm clock source code.
